---
description: 執行完整程式碼、資料庫與網頁畫面自我檢查
---
請依序執行以下自我檢查步驟，不可跳過：
1. 檢查 `git status`，確認沒有誤加入 `.env` 或暫存垃圾檔。
2. 執行 `pytest -v`，若有任何測試失敗，請先分析原因並修復後重新執行。
3. 啟動 FastAPI 開發伺服器（若尚未啟動）。
4. 使用 `/browser` 打開 `http://127.0.0.1:8000`，實際操作最新開發的功能並切換「會員/專員」視角檢查畫面與 Console Error。
5. 全部通過後，執行 `python scripts/backup_db.py` 備份目前正常的資料庫，並幫我準備好 `git add .` 與 `git commit -m "..."` 指令讓我做回朔點存檔。
